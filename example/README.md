# abrova_auth_example

Example app for the Abrova Auth Flutter SDK: anonymous sign-in, e-mail sign-up and sign-in, sign-out and account
deletion.

1. Turn on Abrova Auth and the anonymous and e-mail methods for your project in the Abrova Console.
2. Run the app and paste your public project key (`ab_live_...`) into the API key field, or replace
   `ab_live_YOUR_PUBLIC_KEY` in `lib/main.dart`.

```bash
flutter pub get
flutter run
```
